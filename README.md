# Sevana Sub-Modules

This repo contains multiple independent frontend modules for the Sevana platform.

## Donations & Aid Module
👉 [`sevana-donations/Sevana-Donations-And-Aid`](./sevana-donations/Sevana-Donations-And-Aid)
```bash
cd sevana-donations/Sevana-Donations-And-Aid
npm install
npm run dev
```

## Camps Module
👉 [`sevana-camps/Sevana-Camps-Module`](./sevana-camps/Sevana-Camps-Module)
```bash
cd sevana-camps/Sevana-Camps-Module
npm install
npm run dev
```

Both modules share the same design system (colors, spacing, fonts) defined independently in each module's `src/index.css`, so they'll look visually consistent when eventually combined into one app.
